# 📦 RetourenManager

## Projektbeschreibung

Der RetourenManager ist eine Webanwendung zur einfachen Verwaltung von Kundenretouren.

Die Anwendung ermöglicht es, Retouren zu erfassen, zu verwalten und übersichtlich darzustellen. 
Durch ein Dashboard, eine Suchfunktion und eine Statusverwaltung können Retouren effizient bearbeitet werden.

Das Projekt wurde im Rahmen der Abschlussprüfung als Fachinformatiker für Anwendungsentwicklung entwickelt.


## Funktionen

✅ Neue Retouren erfassen  
✅ Pflichtfeldprüfung beim Speichern  
✅ Retourenübersicht mit allen Informationen  
✅ Statusverwaltung:
- Offen
- Bearbeitet
- Erledigt

✅ Dashboard mit Anzahl der Retouren  
✅ Suche nach Kunde oder Bestellnummer  
✅ Löschen von Retouren mit Sicherheitsabfrage  
✅ Automatische Aktualisierung der Daten  


## Verwendete Technologien

- CSS3

- Express.js

- SQLite
